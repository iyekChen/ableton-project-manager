# Ableton Project Manager Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Search, sort, group, and pin your Ableton Live projects, with Overview and Detail views
- Tag projects with Stage, Genre, and Collection, and filter by Stage or Genre
- Collections: order a tracklist, assign track roles, batch-add projects, and see an energy scale from each bounce
- Play the latest bounce inline; playback keeps going after the Raycast window closes
- Browse bounces, including external bounce folders and files
- View sets with BPM, key, and time signature parsed from `.als` files
- Per-project Markdown notes and lyrics, in the project folder or a folder of your choice (e.g. an Obsidian vault)
- Picks up projects renamed or deleted in Finder, and restores tags when a project is put back from the Trash
